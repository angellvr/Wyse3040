# Ejemplo de base de conocimiento

Cada fichero `.md` de esta carpeta se carga en el contexto del asistente.
Esta carpeta NO se sube a GitHub (salvo este ejemplo): copia aquí información fija de la empresa.

Ideas de ficheros:
- `servicios.md`: catálogo, tarifas, condiciones.
- `proveedores.md`: proveedores habituales, qué facturan, cada cuánto.
- `clientes-clave.md`: clientes importantes y particularidades.
- `procedimientos.md`: cómo se cierra el mes, plazos de IVA, quién hace qué.
